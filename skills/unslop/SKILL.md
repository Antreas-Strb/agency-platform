# unslop

Apply to every human-facing string the agent writes: commit messages, PR bodies, Discord, client drafts, Notion.

## Do
- Short sentences. Concrete nouns. What changed and why.
- Keep Linear IDs, URLs, commands, numbers.

## Don't
- "In today's fast-paced world", "robust", "seamless", "leverage", "delve", "it's important to note"
- Emoji stacks, filler hedges ("might potentially", "it seems like perhaps")
- Restating the ticket as poetry

## Eval
A teammate can skim the text in 10 seconds and know what happened.
